# Go2 激光路线准备验证记录

本记录对应 2026-10-23 的最终代码检查，范围为无实物准备。
`manifest.json` 固定源文件 SHA-256 和证据包 SHA-256；`verification.json` 包含被测公共代码
的 SHA-256。`summary.json` 汇总结果，完整日志、数据库、栅格与轨迹在 `evidence.tar.gz`。

## 已完成的工作和证据

- **官方资料与仓库同步**：开发前与交付前均 fetch `ysgo2`，本地基线与远端均为
  `31bcc7e`，无落后提交。L1、L2 和 Go2 ROS 的接口来源固定到官方提交，详见
  [运行指南](../../../docs/GO2_LIDAR_PREPARATION.md)。未使用推测的商用建图服务编号。
- **可配置雷达/IMU/定位适配**：两份配置分别使用已有 TF 和工作站 ICP 里程计。
  实际 ROS 测试收到 133 帧有效点云及对应 IMU；检查字段、时间、安装 TF 和机身倾角。
  原始三维点云来自合成传感器，未测试真实 L1/L2。IMU 是记录输入，不是融合结果。
- **保存地图重定位门控**：20 项激光专项测试通过，覆盖大小端和行填充、重复字段布局、
  时间同步与跳变、地图身份与非法原点、四个非零朝向、对称地图拒绝、里程计单独不能
  确认保存地图、过期数据、计算超时及恢复不续跑。五个朝向的完整二维往返均通过。
- **激光建图到导航接入**：实际运行 RTAB-Map ICP 和建图节点，收到 148 条有效里程计、
  3 次地图消息，成功导出 `.npz`。在线定位与现有 `NavigationRuntime` 接入后产生
  14 次内存分析指令；没有任何运动话题/SDK 出口。在线确认匹配 51 帧。
- **数据记录与回放**：133 帧有效记录中 129 帧在回放中确认匹配，其余 4 帧用于两次
  连续确认。记录同时保留 4 条故障/结束事件，包含启动迟到、超时和正常结束，未删除。
- **断流与恢复**：ROS 测试主动中断点云 0.6 s；超时停止分析指令，后续地图位姿恢复，
  但没有重新使能，所以不会自动续跑。原有 21 个 mock 场景也全部通过。
- **保留视觉与底层路径**：未修改 `deploy/deploy_mujoco`、`deploy/deploy_real` 或公共
  导航算法。原有 14 项 EDU 测试、30 项公共导航测试，以及七个 MuJoCo/视觉/几何
  回归脚本通过。新增激光专项被纳入 `verify_offline.py`。总计 64 项上述单元测试，
  不与 mock/ROS 场景相加计算可靠性或成功率。
- **TX1 运行准备**：已写明工作站优先、依赖、配置、建图、导图、只读采集、在线分析、
  回放命令及机身高度/时间/外参要求。本轮没有安装、连接或部署 TX1/机器狗。

## 数值结果的适用范围

五个二维理想往返从 0°、−30°、30°、60°、180° 启动，分别耗时
28.6、28.3、28.3、30.2、40.5 仿真秒，返回真值距离为 0.145–0.148 m。
本场景只走 1 m 后返回，验收阈值为返回距离 ≤0.20 m、总时长 ≤70 s、模型检测碰撞为零。
该测试没有真实步态、接触动力学、动态障碍，也不能证明刚好容纳机身的窄通道可通过。

ROS 试验中末端 ICP 平面误差约 0.00056 m，是无噪声合成几何、0.3 m 短距离、平面运动
下的结果，**不能解释成雷达或机器狗的实测定位精度**。算法局限、未知空间处理和全局
搜索边界均见运行指南。本轮不是通用三维 SLAM、紧耦合 LIO 或任意初始位置导航验收。

## 复核命令

在仓库根目录、安装相应开发依赖后，使用新的输出目录：

```bash
python deploy/navigation/verify_offline.py --with-mujoco --output outputs/recheck-common
python -m deploy.lidar.run_offline --output outputs/recheck-lidar-planar
source /opt/ros/jazzy/setup.bash
python -m deploy.lidar.ros_smoke --output outputs/recheck-lidar-ros --domain 87
```

三者均须退出 0，且对应报告 `passed=true`。实际运行前按指南核对依赖和 ROS domain。
源码语法按 Python 3.8 解析通过，不代表已在 Python 3.8 或 TX1 的 ARM 原生环境运行。
ROS 工作站版本见 `environment.json`。

证据包中：

- `final-regression/`：当前完整离线回归日志、源码校验与旧 mock 轨迹。
- `final-planar/`：地图、五条逐周期轨迹和矩阵报告。
- `final-ros/`：实际 ROS 节点日志、RTAB-Map 数据库、导出地图、采集记录、在线分析、回放。
- `localization-load.*`：既有数据库加载检查，加载前后 SHA-256 相同。该项仅检查加载与
  文件保持，不算外部 LIO 实际接通或全朝向 RTAB-Map 定位验证。
- `diagnostic-before-fix/`：保留本日开发中修复前的失败日志和报告，包括一次采集模块
  语法错误。它们不属于最终通过批次，不应被混入通过率。更早的临时调试日志未保留。

完整家庭场景的十组视觉端到端矩阵本轮未重跑；历史证据保持原样。实录数据、真实停止
距离、负载影响、雷达扫描时序与 TX1 长时性能仍待设备到位后验证。
